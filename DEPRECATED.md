# Dualcut is deprecated

Dualcut is no longer the primary home for video-editor development. New work
should happen in [shrimply](https://github.com/soirihiroka/shrimply), which is
the recommended successor.

This repository remains available for its history and existing release
artifacts. If you are maintaining an existing Dualcut project, the documented
Flatpak releases remain available; however, new features and bug fixes should
be evaluated for porting to shrimply instead of being added here.

The project document and agent-editable workflow are useful concepts to carry
forward. Please preserve their provenance when porting them, and check
shrimply's current schema and contribution guidance before opening a change.
